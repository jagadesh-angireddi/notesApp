#  Notes App

A simple React Notes application where users can add, view, and delete notes.  
Used UseState hooks, event handling, and conditional rendering.

---

##  Working

- User enters a **title** (max 20 characters) and **details**
- If both fields are empty → an error message is shown
- Notes get added to the list with a unique ID
- All notes are displayed on the right side
- Each note has a **Delete** button to remove it
- Smooth UI built using TailwindCSS

---


## 📦 Installation

### 1️⃣ Clone the project
```bash
git clone https://github.com/your-username/notes-app.git
```

### 2️⃣ Go into the folder
```bash
cd notes-app
```

### 3️⃣ Install dependencies
```bash
npm install
```

### 4️⃣ Start the development server
